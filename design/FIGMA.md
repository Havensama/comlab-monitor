# UI/UX design (Figma)

The screens were designed in Figma first; the Java Swing front end follows these frames.

**Figma file:** https://www.figma.com/design/PfDX75VxfcU0FIVsF0QWNc/UE-CompLab-%E2%80%93-Login--Modern-

| Frame | Used by |
|---|---|
| Login – Desktop | Student kiosk login |
| Workstation Check – Desktop | Student, after login |
| Student In Session | Session bar while using the PC |
| Admin Login | Admin console |
| Admin Dashboard | Admin console, live PC map |
| Session Logs | Admin console |
| Reports | Admin console |

## Design tokens

| Token | Student (orange) | Admin (violet) |
|---|---|---|
| Accent | `#F47A20` | `#7C3AED` |
| Accent hover | `#E06A12` | `#6D28D9` |
| Accent soft | `#FFF4EC` | `#F3EEFF` |
| Brand / deep | `#C8102E` | `#5B21B6` |

Shared: text `#18181B`, secondary text `#52525B`, muted `#A1A1AA`, canvas `#F6F6F7`,
border `#E4E4E7`, success `#16A34A`, warning `#B45309`, danger `#DC2626`.

Fonts: **Poppins** (headings), **Inter** (body). Layout: Figma auto-layout, 1920×1080 frames.
